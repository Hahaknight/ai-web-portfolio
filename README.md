# AI 建站作品集 · 4 行业实站演示

**四个真实行业的小型官网/作品站，从花店到摄影工作室——每个都是可直接浏览的完整站点。**

🔗 **在线浏览：<https://hahaknight.github.io/ai-web-portfolio/>**

## 作品清单

| 站点 | 行业 | 类型 | 目录 |
|---|---|---|---|
| 沐光瑜伽 | 瑜伽/健身 | 商城店官网 | [`yoga/`](yoga/) |

每个站点包含：完整首页（hero/服务或作品展示/信任区/联系）、桌面与移动端截图、独立可部署的静态页面。

## 这是什么/不是什么

- **是**：面向本地小商户的建站交付演示——打开即能看、能摸、能对比行业风格差异
- **不是**：模板引擎或建站系统；每个站点都是独立手作的静态页面

## 自部署

纯静态，零依赖，零构建步骤。

```bash
git clone https://github.com/Hahaknight/ai-web-portfolio
# 直接打开任意子目录的 index.html，或开启 GitHub Pages
```
